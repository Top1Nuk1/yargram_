# Yargram 0.1 — направление развития

Текущая версия остаётся 0.1. Сейчас тестирование идёт с сервером на ПК владельца; друзья заходят по ссылке через браузер. Приложения для ПК/телефонов и публичный сайт — будущие этапы, не готовые функции текущего выпуска.

## Сайт и приложения

- Отдельный главный сайт с объяснением мессенджера, возможностями и скриншотами.
- Кнопка «Веб-версия» открывает web.yargram.com либо web.<выбранный домен>. Домен ещё не выбран.
- Кнопка загрузки приложения под устройство. Android: APK и/или магазин. iPhone: App Store/TestFlight; для ранней веб-версии — инструкция установки PWA на главный экран. Простое скачивание файла не устанавливает iOS-приложение.
- React/Vite для веба, Electron для ПК, React Native для Android/iPhone с общими API и типами.
- Push, фоновые звонки, безопасное хранение сессий и восстановление соединения — отдельная работа для каждой платформы.
- Позже Cloudflare для домена/HTTPS/туннеля к серверу. Cloudflare Tunnel не заменяет backend, PostgreSQL или TURN для звонков. Для полностью независимой работы от ПК потребуется перенос backend и данных на хостинг.
- Текущая Radmin-ссылка доступна только участникам соответствующей VPN-сети. Произвольная интернет-ссылка без установки сертификатов требует публичного HTTPS endpoint, например туннеля.

## Вход через Telegram

Вариант: приложение создаёт попытку входа, открывает t.me/<bot>?start=<случайный непрозрачный токен>. Если ссылку открыть не удалось — показывает username бота и отдельный код из 5 символов. Код действует 5 минут, используется один раз; генерация нового отменяет старый. Нужны ограничения попыток по пользователю/сессии/IP и защита от перебора.

Бот показывает, что именно подтверждается, и запрашивает явное подтверждение входа. Нельзя привязывать чужую активную сессию только по введённому коду: нужна защита от пересылки кодов и подмены попытки входа. Сервер проверяет источник сообщений бота и атомарно завершает попытку; клиент ожидает результат и показывает приветствие. Bot token хранится только на сервере.

Имя, username (может отсутствовать), доступная фотография импортируются при создании аккаунта. Описание профиля через Bot API не гарантируется; оставлять пустым, если недоступно. Telegram ID — внешний стабильный идентификатор, username не подходит как ключ аккаунта. Коллизии username Yargram разрешаются явно. В Yargram профиль можно менять независимо от Telegram. Предусмотреть привязку к существующему аккаунту и восстановление доступа.

## Темы и стиль

Пользовательские цвета, обои и оформление с предпросмотром и сбросом. Настройки принадлежат аккаунту и синхронизируются между устройствами; предусмотреть читаемость текста и доступность. Сейчас исправлено серверное сохранение themeColor/wallpaperUrl; полноценный редактор ещё предстоит сделать.

## Личное «Избранное»

Нужен полноценный чат с самим собой: текст, фото, файлы, ответы, редактирование, удаление и поиск. Каждый аккаунт видит только своё содержимое на всех устройствах. Не смешивать этот чат с закладками сообщений и отдельными текстовыми заметками текущей версии. Сервер должен проверять владельца каждого сообщения и вложения.

## Ближайшая техническая база

Исправная сборка, PostgreSQL с безопасным переносом JSON, тесты прав доступа и сохранности, резервные копии, сессии устройств, устойчивая синхронизация, TURN и push. Решение о сквозном шифровании принять до расширения клиентов.
