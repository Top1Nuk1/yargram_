# Yargram 0.1 — текущее обновление

Реализуемые изменения: бело-голубое оформление с фиолетовыми акцентами, анимации появления сообщений и элементов с поддержкой prefers-reduced-motion, отдельные разделы настроек аккаунта/приватности/оформления/уведомлений. Иконка сохраняется.

Время посещения: точная дата при включённой видимости, иначе серверные категории недавно/на прошлой неделе/в прошлом месяце/давно. Online также скрывается. Время переводится в часовой пояс устройства смотрящего без запроса местоположения. Приблизительные категории отражают интервалы 3/7/30 дней, а не календарные недели/месяцы.

Исправления: сброс обоев пустым URL, применение выбранного цвета к CSS-переменным, очистка сохранённого точного статуса при переключении приватности, гонка регистрации обработчиков Socket.IO при подключении, переносимость пути вложений на Linux.

Личное Избранное реализуется как отдельная переписка с одним участником — владельцем. Старые заметки и закладки сохраняются отдельно. Вложения выдаются только по временным подписанным ссылкам: путь без подписи отклоняется, подпись истекает (по умолчанию 24 часа), а при запросе сервер проверяет, что аккаунт из ссылки по-прежнему владеет файлом или участвует в диалоге с сообщением, к которому файл прикреплён. Удаление сообщения отзывает доступ у собеседника. Остаётся пересылка самой ссылки внутри срока действия — для полного запрета нужны отдельные сессии/куки вместо ссылок.

Запись медиа: видеокружки с автоматической остановкой на 60 секундах и круглым плеером; голосовые без программного лимита времени, но с прежним пределом файла 100 МБ и ограничениями памяти браузера. WebM новых записей получает метаданные длительности. Неизвестная длительность старых записей больше не подменяется одной секундой. Для записи нужны HTTPS, разрешение микрофона, а для кружков также камеры. Сервер проверяет объявленную клиентом длительность кружка; анализ фактической длительности контейнера на сервере пока не выполняется.

Папки, черновики и отложенная отправка уже реализованы (см. docs/API.md). Группы/каналы, вход через Telegram, полноценный редактор тем и внешний push/TURN — следующие выбранные этапы, не следует считать их готовыми на основании этого документа. Подробности: TELEGRAM-FEATURES.md.
