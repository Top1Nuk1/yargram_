# Yargram — заметки о проекте

## Семантика блокировки (согласовано с пользователем)

Как в Telegram: заблокированный **может** писать (сообщение сохраняется и видно ему), но
блокирующему оно не доставляется — ни в сокете, ни в истории, **даже после разблокировки**.
Блокирующий писать не может, пока не снимет блокировку. Звонки запрещены в обе стороны.
Заблокированный видит профиль блокирующего без аватара и со статусом «был(а) давно».

## Твёрдые правила

- Версия остаётся **0.1** (`package.json` не bump'аем), «0.2» — только название набора фич.
- Запускает приложение сам пользователь через `Запустить Yargram.bat`; агент не запускает сервер.
- Перед коммитом: `npm run verify` (typecheck + lint + test).

## Грабли, на которые уже наступали

- **embedded-postgres не стартует из-под админа** («administrative permissions is not permitted»).
  Поэтому `launch-yargram.ps1` не само-элевируется; повышение вынесено в `prepare-yargram-access.ps1`.
- **`.ps1` в репозитории — только UTF-8 с BOM**, иначе PowerShell 5.1 коверкает кириллицу.
- **`.gitattributes`: побеждает последнее правило** — общий `* text=auto eol=lf` должен идти *перед*
  `*.bat/*.cmd/*.ps1 eol=crlf` и `*.png binary`.
- **vitest на Windows иногда грузит файл двумя модулями** (`C:/…` и `c:/…`). Из-за этого ломаются
  `instanceof` и общие синглтоны модулей (состояние `lib/media-links.ts`). Тесты не должны зависеть
  от идентичности класса и от секретов, задаваемых «снаружи» приложения.
- **SVG-значки**: кончик луча — квадратичная Безье через свою вершину, `control = 2·tip − midpoint`.
  Звезда 8 лучей (R 23, r 17.9), розетка 12 (R 23, r 19.6), viewBox 48×48.
- **`git commit` из Bash блокируется**, если текст сообщения содержит слово «PowerShell» или маску
  вида `*.ps1`/`*.bat` — защита принимает это за вызов оболочки. Формулируй сообщение иначе.
- Значки в переписке терялись из-за `participantUser()` — он не переносил `isVerified`/`badge`.
  Перенос есть, прикрыт тестом.
- Шапка аватарки с цветом по **id** аккаунта: суммы кодов UUID почти всегда давали один и тот же
  остаток по `mod 7`, у всех «Удалённый аккаунт» был одинаковый фон. Используем мультипликативный
  хеш и `seed={user.id}` во всех `Avatar` (хелпер `avatarProps` в `apps/web/src/lib/user.ts`).
- Превью-скриншоты требуют `NODE_ENV=production` — статика SPA в dev не отдаётся.
