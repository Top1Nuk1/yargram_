# Yargram — заметки о проекте

Версия `0.1.0` («0.1.0 ЗБТ» в интерфейсе, `package.json` не bump'аем). Документация — `Функции
Yargram.txt`, `ТЗ 0.2 — Обновление Communication.txt`. Сервер поднимает сам пользователь
(`Запустить Yargram.bat`). Перед коммитом `npm run verify`. Детали — в `2026-09-*.md`.
Очередь: каналы → Web Push → устройства и сессии.

## Семантика (согласовано)

- **Блокировка** — как в Telegram: заблокированный пишет, но до блокирующего не доходит ни сокетом,
  ни в истории, даже после разблокировки; блокирующий писать не может, звонки закрыты.
- **Удалённый** — мягко (`isDeleted`): почта и ник заняты, возврат `POST /api/admin/:id/restore`,
  писать и звонить нельзя (403 `ACCOUNT_DELETED`).
- **Замороженный** — входит и читает, но не пишет (`assertAuthorWritable`).
- **SCAM** — только владелец: рамка `ScamBadge` и подмена описания на `SCAM_BIO_WARNING` **на
  чтении** (`toPublicUser`), снятие отметки возвращает прежнее описание. Текст не копируется
  (`ScamWarning`). У группы — `SCAM_GROUP_WARNING` и подмена описания группы (`groupDescriptionFor`).
- **Знаки группы** — владелец Yargram выдаёт галочку, значок Yargram и отметку SCAM самой группе
  (а не её создателю), через раздел «Группа» в админ-панели. Подмена описания живёт на чтении,
  описание редактировать нельзя, пока отметка стоит.
- **Юзернеймы** — занят и основной ник, и любой дополнительный (`findByUsername` ищет по обоим).
  Дубль «основной ник внутри дополнительных» отбрасывается молча, а не отменяет список.
- **День рождения** — год необязателен (`MM-DD`).
- **Группы** — роль считается (`groupRoleFor`), права проверяет `groupCan()`; мьют: в записи `null` =
  бессрочно, в `POST /groups/:id/restrict` наоборот.

## Доступ и клиент

Друг заходит по HTTP `http://26.53.76.128:3000`; HTTPS — только для звонков. Мультиаккаунт —
на клиенте (`lib/accounts.ts`); `MessengerScreen` рендерится с `key={token}`.

## Грабли

- **Хранилище молча режет незнакомые поля:** новый флаг дописывать и в схему чтения, и в `update`
  обоих репозиториев — иначе работает, но не сохраняется.
- `participantUser()` (`lib/conversation.ts`) собирает `User` вручную — каждый новый флаг
  (`isFrozen`, `isDeleted`, `isVerified`, `badge`, `scam`) пробрасывать; `profile:updated` обновляет
  и свой профиль.
- **`title` у `<svg>` в TSX запрещён**, а `<title>` внутри `<svg>` попадает в `textContent` и ломает
  сравнение имён. Подсказка — на обёртке `<span title="…">`.
- **После правок агента приложение надо перезапустить:** серверный код живёт в памяти процесса —
  кнопка видна, её запрос 404.
- **Две правки одного файла в одном сообщении теряются** — правь последовательно и проверяй чтением.
- Стенд скриншотов — скилл `yargram-screenshots`; тесты и `npm run build` одновременно
  не запускать (postgres-хуки падают по таймауту).
- `.ps1` — только UTF-8 **с BOM** (`npm run check:ps`); `git commit` из Bash блокируется на слове
  «PowerShell» и масках `*.ps1`/`*.bat` в сообщении.
