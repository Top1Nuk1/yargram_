Очерёдность:
1. **Группы** — создание, название + аватар, описание, приглашение по ссылке,
   добавление/удаление участников, владелец, администраторы, права админов,
   запрет отправки сообщений, запрет медиа, мут участника, закрепления, список
   и поиск участников, история изменений группы.
   Права: 👑 Владелец / 🛡 Администратор / 👤 Участник / 🚫 Ограниченный,
   включаются **по отдельности**: отправка сообщений, медиа, ссылки, опросы,
   добавление участников, закрепление, изменение информации, удаление сообщений.
2. **Каналы** — другой тип общения, а не «группа с другим названием»: описание,
   аватар, подписчики, администраторы, публикации, закреп, реакции, комментарии,
   просмотры.
3. **Web Push + Service Worker** — уведомления при закрытой вкладке (сообщения,
   упоминания, звонки, ответы, добавление в группу) и настройки:
   все сообщения / только упоминания / только личные / выключить.
4. **Устройства и сессии** — список активных сеансов, «Завершить сеанс»,
   «Завершить все другие сеансы», отзыв токенов. Фундамент для мобильных приложений.
